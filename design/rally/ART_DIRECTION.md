# VOLLEY HUB / RALLY — logo-design-skill exploration

This is a **concept checkpoint**, not a shipped production rebrand. The source mark is vector SVG and the existing deployed app is untouched. The previously assembled CONTACT Rive mark is not reused.

## Process applied
Source: [kaankiziltug/logo-design-skill](https://github.com/kaankiziltug/logo-design-skill), particularly SKILL.md and the redesign/typography/SVG/testing references.

1. Brief: volleyball scores-and-fixtures PWA; user wants editorial sports-quality brand aligned with dark navy, no generic basketball/volleyball illustration, no artificial chrome or glitches.
2. Research: LOVB / Gretel (connected motion in letters), Volleyball World / Blaze Type (width/rhythm of letterforms), MotoGP / Pentagram (movement as typographic structure). Study the principles, not the protected marks.
3. Word map: serve → rally → exchange → return → connection; v–o and ll are structural opportunities.
4. Explored ten directions; developed **FUSED, CADENCE, FORWARD** and inspected the same width, monochrome and real 200 px context.
5. Outlined SVG paths; checked XML and ensured no fonts, live <text>, raster, masks or filters in logo masters. True 16/32/64 px symbol previews and one-color/reversed versions are included in the ZIP preview kit shared with the owner.
6. Recommendation: FUSED. Distinctive V/O shared shoulder, a purposely repeated LL top rhythm. Risk: V/O junction and icon still require final optical refinement.
7. Pause before changing main app or replacing the Rive file until the mark's shape is accepted; animation must come **from** the final geometry.

## Fonts and honesty
The non-custom parts use outlined shapes based on Inter Display Black (SIL OFL 1.1 / Apache 2 license). The v and o were redrawn, LL stems created separately, spacing edited. No font binaries are included. This is not an all-original alphabet and **not trademark cleared**.

## Review gates
- Wordmark at 200 px must be instantly readable.
- Symbol at 16 and 32 px: check clarity and false readings.
- One-colour and reverse variants must keep the same silhouette.
- No seam hairlines; optical spacing of V/O, LL, E/Y, and HUB.
- Test competing sport brands for similarity and do a real trademark clearance check before launch.
- Full Rive motion design *only after sign-off*: one soft forward serve gesture expressed as the V–O shoulder, short one-shot, touch replay, reduced motion fallback.
