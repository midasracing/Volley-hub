## O projekcie

**Kiedy Siatka?** to aplikacja webowa do sprawdzania, kiedy odbywają się mecze siatkówki i jakie padły wyniki. Jest projektowana przede wszystkim na telefon, ale działa też na komputerze.

Bez zakładania konta. Można dodać ją do ekranu głównego telefonu jako PWA.

## Co znajdziesz w aplikacji

- **Kalendarz** — mecze na wybrany dzień, z filtrami lig i grup.
- **Wyniki** — rezultaty spotkań, sety i status meczu.
- **Rozgrywki** — terminarze, tabele i drużyny z wybranych lig w Polsce, Włoszech i Japonii.
- **Ulubione** — własna lista drużyn i rozgrywek zapisywana w przeglądarce.

## Uruchomienie lokalne

Potrzebujesz **Node.js 20+** i npm.

```bash
git clone https://github.com/midasracing/kiedysiatka.git
cd kiedysiatka
npm install
npm run dev
```

Pozostałe polecenia: `npm test` (testy) oraz `npm run build` (wersja produkcyjna).
